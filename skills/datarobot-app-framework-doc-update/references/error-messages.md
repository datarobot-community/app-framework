# Error messages

Follow [Voice and tense](grammar-and-punctuation.md#voice-and-tense), [Words to avoid](words-to-avoid.md#words-to-avoid), and [Periods](grammar-and-punctuation.md#periods). Error-specific rules:

| Rule | Guidance |
| --- | --- |
| Articles | Do not start with *the* or *a* (except multi-sentence messages). |
| Modals | Prefer *cannot* over *could*. |
| Field names | Capitalize *ID* unless it is a field name; use exact API field names in API responses. |
